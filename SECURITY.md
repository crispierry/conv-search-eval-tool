# Security

This is a private project and may eventually handle sensitive search queries, conversation logs, reviewer notes, or internal evaluation data.

## Current State

No application code, data ingestion, or deployed service exists yet.

## Data Handling Principles

- Do not commit real user conversations, secrets, API keys, or private datasets.
- Use synthetic or redacted examples in documentation.
- Treat future evaluation exports as potentially sensitive.
- Prefer least-privilege access for any future integrations.

## Reporting Issues

For now, raise security concerns directly with the repository owner.
