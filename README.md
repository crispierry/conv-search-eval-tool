# Conversational Search Evaluation Tool

A product and research workspace for designing an evaluation tool for conversational search experiences.

This project is intentionally documentation-first. The goal is to clarify what should be evaluated, how reviewers should judge quality, and what kind of workflow would make the results useful before choosing an application stack.

## Current Focus

- Define what a strong conversational search experience should do.
- Brainstorm evaluator workflows, scoring rubrics, and reporting needs.
- Capture early product decisions in a durable place.
- Prepare the repository for future implementation.

## Working Agreement

This repository should stay small and intentional until the evaluation experience is clear. Prefer writing down product intent, example workflows, and open questions before introducing implementation complexity.
