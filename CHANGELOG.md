# Changelog

All notable changes to this project will be documented here.

## 2026-06-01

- Reworked the Human Review view to mirror Automated Detail with query navigation, conversation map, search results, and a dedicated Human Judgment column.
- Added field-level human review state for conversation blurbs, result validity, ranking position, AI custom blurbs, and follow-up suggestions.
- Added Check/X controls and commentary fields for conversation blurbs, AI custom blurbs, and follow-up suggestions.
- Added result-level controls for whether a returned title is valid for the query and which rank position is correct.
- Made the Human Judgment column vertically scrollable so long gate and follow-up review sections remain reachable.
- Preserved Stage 1 correctness gate review controls in the Human Judgment column.
- Documented open follow-up work for human review scoring semantics and rank-position approval behavior.
- Added open-source publication artifacts: MIT license, code of conduct, third-party notices, issue templates, pull request template, and readiness notes.
